REVISION: REWORK THE HERO INTERACTION AND COLLECTION

The current hero typography and overall visual direction are working well. KEEP the following:

- warm off-white background
- near-black typography
- large bold grotesk headline
- “I FIGURE THINGS OUT.” as the main statement
- minimal top navigation
- restrained supporting copy
- generous whitespace
- overall clean editorial aesthetic

Do NOT redesign the entire page.

The main problem is the personal collection. It currently feels like several unrelated decorative UI elements placed around the headline. Rework the collection so it feels like ONE physical, art-directed still life existing in the same spatial world as the typography.

CORE IDEA:

The collection should feel like a personal desk / still life that has been art-directed, not like floating interface widgets.

Use temporary placeholder assets for now. Do NOT spend effort creating final personal objects.

1. realistic book object
2. small unusual keychain object

5. handwritten paper fragment
6. subtle sound/music visual element

The final website will replace these placeholders with real photographs of Shanvi's actual objects.

VISUAL TREATMENT:

- objects should look physical and tactile
- realistic lighting and shadows
- editorial still-life photography / premium 3D object aesthetic
- no flat vector icons
- no generic UI cards
- no glassmorphism
- no floating dashboard widgets
- no obvious symbolic illustrations
- no excessive gradients

IMPORTANT:

Do not distribute all objects evenly around the screen.

Create hierarchy:

- 2–3 dominant objects
- 2 secondary objects
- 2–3 subtle discoveries

Allow some objects to overlap or partially intersect the typography.

The collection should feel composed as one visual scene.

Some objects can be partially cropped by the viewport.

Do not give every object a label.

Do not explain what every object represents.

--------------------------------------------------

CURSOR / MOUSE INTERACTION

Introduce a subtle custom cursor-following interaction inspired by high-end interactive studio websites.

The cursor itself remains simple.

Create a small contextual indicator that follows the mouse with slight easing / lag.

The indicator should be small and unobtrusive.

When the cursor is moving through ordinary hero space:

show nothing or a very subtle dot.

When approaching an interactive collection object:

show:

LOOK

When hovering directly over an object:

show:

VIEW

When hovering over a project navigation region:

show:

ENTER →

When hovering over an external link:

show:

OPEN ↗

The cursor indicator should follow the actual mouse position with a small delay, creating a physical/tactile feeling.

Do NOT create:

- giant cursor circles
- glowing cursor effects
- permanent cursor trails
- neon effects
- excessive particles
- distracting animations

The cursor should feel like a quiet guide.

--------------------------------------------------

OBJECT RESPONSE

Objects should respond based on cursor proximity.

When the cursor approaches an object:

- move it 5–15px toward/away from cursor
- rotate 1–4 degrees
- scale maximum 1.02–1.05
- optionally create very subtle depth/parallax

The response should be soft and physical.

Bhondu/keychain:
- gently swings or rotates

Book:
- subtly shifts/tilts

Bangles:
- slightly separate or shift against one another

Rock:
- barely moves

Paper:
- subtly lifts or shifts

Sound element:
- gently reacts visually when hovered

Do not make objects fly around.

Do not continuously animate objects when the cursor is stationary.

The interaction should feel discovered rather than announced.

--------------------------------------------------

DISCOVERY

The user should understand the interaction without instructions.

Do NOT add:
“Move your mouse”
“Click the objects”
“Explore the collection”

Instead:

The first subtle object movement should naturally communicate that the scene is interactive.

The contextual cursor label should appear only when relevant.

--------------------------------------------------

WORK ENTRY

Create one clear interactive pathway from the hero into the work section.

The user should be able to discover:

WORK → ENTER

through cursor movement.

When the cursor enters this region:

- contextual cursor changes to ENTER →
- relevant collection objects subtly respond
- project-related visual hint can appear

On click, transition smoothly into:

SELECTED WORK

01 — KUTIR

Do not create a complicated cinematic transition yet.

Prioritize a clean, satisfying interaction.

--------------------------------------------------

The hero should feel like:

A very clean editorial portfolio interrupted by a strange personal still life.

NOT:

A collection of decorative UI components.

NOT:

An interactive game.

NOT:

A 3D showcase.

“Okay, this leads into her work.”
