HERO REVISION — REWORK THE PERSONAL COLLECTION INTO AN OPTIONAL “MESS → COMPOSITION” INTERACTION

Keep the current overall website design system and typography. Do NOT redesign the rest of the website.

The current hero direction is close, but the personal collection needs to fundamentally change.

The new concept:

A deliberately art-directed CLUTTER OF OBJECTS sits within the hero.

The objects initially appear loosely scattered, overlapping, and unresolved.

When the user chooses to interact with them, the objects gradually discover relationships with each other and begin moving into a beautiful, intentional composition.

The interaction represents:

MESS → OBSERVE → FIND → CONNECT → COMPOSE

This subtly reflects Shanvi's way of approaching ambiguous problems:

“I figure things out.”

IMPORTANT:
This is NOT a game.
Do NOT recreate Gardenscapes.
Do NOT add scores, lives, timers, levels, points, progress bars, rewards, game HUDs, cartoon graphics, or game-like UI.

The hidden-object mechanic is simply an optional layer of exploration within a portfolio homepage.

A visitor who does not interact with the objects should be able to scroll normally and understand the portfolio immediately.

--------------------------------------------------

Replace the current floating individual object arrangement with ONE concentrated visual field of objects.

Do not scatter individual objects across the entire viewport.

Create a defined “mess” occupying approximately the central/right portion of the hero, while keeping the headline readable.

The clutter should feel like one physical collection that has been emptied onto a surface.

Use approximately 20–30 placeholder objects.

Objects can include:

- pencils
- paper scraps
- small mechanical parts
- jewellery
- bangles
- stones
- keys
- cables
- photographs
- little found objects
- unusual household objects
- abstract tactile objects

Among these objects, hide a few meaningful placeholder objects inspired by Shanvi's actual interests:

- a strange keychain placeholder representing “Bhondu”

- colourful bangles
- a small rock
- a handwritten note
- an abstract sound/music-related object
- a small ash/texture-related object

The actual objects will later be replaced with real photographs/assets.

Do not make the meaningful objects visually obvious at first.

--------------------------------------------------
3. ART DIRECTION OF THE CLUTTER
--------------------------------------------------

Use the uploaded visual references as inspiration for the COMPOSITION and ART DIRECTION, not as something to copy literally.

The desired aesthetic is:

- contemporary editorial still life
- tactile physical objects
- carefully art-directed clutter
- playful but sophisticated
- selective colour
- realistic lighting
- soft shadows
- physical depth
- objects overlapping each other
- different scales
- some objects partially hidden
- some objects rotated
- some objects nearly touching
- a few objects almost falling out of the composition

The clutter should feel intentional even in its messy state.

Think:

“A very visually interesting desk/drawer/table emptied out and photographed beautifully.”

NOT:

“30 random icons floating around a website.”

NOT:

“a game scene.”

NOT:

“a Pinterest moodboard.”

NOT:

“a pile of cards.”

--------------------------------------------------
4. IMPORTANT COMPOSITIONAL BEHAVIOUR
--------------------------------------------------

The objects should have TWO distinct visual states.

STATE A — UNRESOLVED

At page load:

The objects are loosely scattered and overlapping.

They have slightly different rotations and depths.

Some are partially hidden behind others.

There is no obvious grid.

The composition should feel unresolved but aesthetically balanced.

The user should be able to look at it and wonder:

“What is going on here?”

STATE B — COMPOSED

When the user interacts with the objects, they begin moving toward a carefully designed final arrangement.

The final arrangement should resemble the uploaded visual references where unrelated objects become a single graphic/still-life composition.

The objects should NOT simply arrange themselves into a neat grid.

Instead, create a visually satisfying composition based on:

- proximity
- scale
- shape
- colour
- orientation
- negative space
- overlap

Some objects can stack.
Some can touch.
Some can sit inside/around other shapes.
Some can frame another object.
Some can remain slightly offset.

The final arrangement should look like it was deliberately art-directed by a designer.

--------------------------------------------------
5. INTERACTION MUST BE OPTIONAL
--------------------------------------------------

This is extremely important.

The interaction should NOT interrupt the visitor's normal portfolio experience.

At page load, do NOT force the user to find anything.

Do NOT show a modal.

Do NOT stop scrolling.

Do NOT require interaction before accessing the portfolio.

Do NOT show a mandatory instruction.

The visitor can simply scroll down and continue through the website.

The interaction exists for people who are curious.

--------------------------------------------------
6. CURSOR-LED DISCOVERY
--------------------------------------------------

Use a subtle custom cursor-following indicator inspired by high-end interactive portfolio/studio websites.

The cursor should remain visually minimal.

When the cursor enters the clutter area, a small contextual indicator can appear near the cursor:

EXPLORE

The indicator should follow the actual mouse with slight easing/delay.

Do not make it huge.

Do not use a glowing circle.

Do not use a permanent cursor trail.

Do not use neon effects.

When the cursor moves over an object that can participate in the interaction:

LOOK

When the cursor is directly over a meaningful/interactive object:

FOUND

When the cursor is over the work navigation:

ENTER →

The cursor itself should communicate interaction rather than adding instructions to the page.

--------------------------------------------------
7. OBJECT DISCOVERY
--------------------------------------------------

Objects should respond subtly to cursor proximity.

When the cursor approaches an object:

- shift 5–15px
- rotate 1–4 degrees
- slightly change depth
- optionally scale 1.02–1.05

The effect should feel physical.

Do NOT make every object aggressively follow the cursor.

Only nearby objects should respond.

Objects should feel as though the user's attention is disturbing the pile.

--------------------------------------------------
8. THE “FIGURING OUT” MOMENT
--------------------------------------------------

The most important interaction:

When the user discovers one of the meaningful objects, it should NOT immediately disappear or open a popup.

Instead, that object begins to move toward its position in the final composition.

For example:

User discovers Bhondu.

Bhondu subtly moves to a specific location.

Then nearby objects begin responding and adjusting around it.

The user discovers another meaningful object.

It moves into another position.

The surrounding objects subtly reorganize.

Gradually, the mess starts becoming a composition.

This should feel like:

“I'm figuring out how these things fit together.”

rather than:

“I completed a hidden-object game.”

--------------------------------------------------
9. DO NOT REQUIRE ALL OBJECTS TO BE FOUND
--------------------------------------------------

The visitor should NEVER have to find every meaningful object.

If they interact with one or two objects:

the composition can partially reorganize.

If they interact with several:

the composition becomes more complete.

If they interact with none:

nothing breaks.

They can simply scroll.

This is an optional discovery layer.

--------------------------------------------------

--------------------------------------------------

11. FINAL COMPOSITION
--------------------------------------------------

The final composition should be the strongest visual moment.

Use the discovered objects to form a beautiful still-life composition inspired by the uploaded references.

The final arrangement should have:

- one clear visual focal point
- deliberate asymmetry
- strong negative space
- overlapping objects
- colour relationships
- scale contrast
- tactile depth
- editorial art direction

The composition should look like something that could exist as a poster, editorial photograph, or contemporary design artwork.

Do not make it look like a completed game board.

--------------------------------------------------
16. MOTION STYLE
--------------------------------------------------

Motion should be:

- soft
- physical
- slightly delayed
- organic
- restrained
- editorial

Use spring-like easing where appropriate, but keep movement controlled.

Objects should never zip across the screen.

Avoid:

- bouncing
- excessive rotation
- particle explosions
- elastic UI
- dramatic cinematic transitions
- constant movement
- flashy effects

The scene should feel almost static until the user interacts with it.

--------------------------------------------------

Use the full interactive clutter composition.

Tablet:
Reduce the number of objects and simplify the interaction.

Mobile:
Do NOT attempt to reproduce the entire desktop clutter.

Use approximately 8–12 objects.

Allow tap interaction instead of hover.

A tap on an object should produce the same subtle “attention → movement → composition” behaviour.

The user must still be able to scroll normally.
