HERO ART DIRECTION — MAJOR REVISION

Use the attached visual references as art-direction references for this revision.

The current typography and overall website design system are good and should remain.

The main thing that needs to change is the relationship between the hero typography and the collection of objects.

The current implementation makes the objects feel like separate decorative elements floating around the headline.

That is NOT the desired direction.

The desired direction is:

TYPOGRAPHY + OBJECTS + SPACE = ONE COMPOSITION.

The hero should feel like an art-directed editorial composition that gradually resolves itself.

--------------------------------------------------
CORE CONCEPT
--------------------------------------------------

The hero represents:

MESS → OBSERVATION → FIGURING OUT → CLARITY

But this should NEVER be explained literally to the visitor.

The visitor should experience it visually.

The starting state is slightly unresolved.

The ending state is a beautifully composed, highly legible visual arrangement.

The phrase:

I FIGURE
THINGS
OUT.

is the central element throughout.

--------------------------------------------------
IMPORTANT VISUAL CHANGE
--------------------------------------------------

Do NOT scatter individual objects around the viewport.

Do NOT make objects look like separate UI components.

Do NOT put objects in cards.

Do NOT place one object in each empty area of the hero.

Do NOT create a “floating objects around text” composition.

Instead, create ONE integrated visual composition.

The objects should exist within the same visual space as the typography.

Objects may:

- partially overlap letters
- sit between words
- sit behind letters
- emerge from behind typography
- sit on top of parts of letters
- overlap one another
- share shadows and lighting
- create visual connections between words
- create small areas of clutter around the typography

The objects and typography should feel like they belong to the same physical/art-directed scene.

--------------------------------------------------
INITIAL HERO STATE
--------------------------------------------------

At page load, create a slightly unresolved but already beautiful composition.

The phrase:

I FIGURE
THINGS
OUT.

must remain clearly readable.

Do NOT obscure the words.

The initial composition should feel approximately:

70% composed
30% unresolved

The visitor should immediately understand the headline.

At the same time, they should notice a strange collection of physical objects integrated into the composition.

The feeling should be:

“I understand what this says, but I want to look closer.”

--------------------------------------------------
OBJECT ART DIRECTION
--------------------------------------------------

Use REALISTIC, PHYSICAL-LOOKING OBJECTS.

Do NOT use generic abstract 3D blobs.

Do NOT use flat vector icons.

Do NOT use simplistic UI illustrations.

Do NOT use tiny generic placeholder symbols.

For this prototype, use realistic photographic or photorealistic assets.

The objects should feel like actual objects photographed for an editorial still life.

Use a mixture of:

- books
- colourful bangles
- unusual keychain
- rocks
- paper
- handwritten notes
- pencils
- stationery
- colourful everyday objects
- jewellery
- small mechanical objects
- found objects
- pieces of material
- photographs
- miscellaneous tactile objects

Among these, include placeholder versions of Shanvi's personal objects:

- Bhondu — unusual keychain
- My Year of Rest and Relaxation — book
- colourful bangles
- small rock
- handwritten writing
- subtle ash-like material

Do not make these objects look like isolated product renders.

They should have consistent lighting, shadows, perspective, scale and material quality.

--------------------------------------------------
VISUAL REFERENCE INTERPRETATION
--------------------------------------------------

Use the attached references for:

- visual density
- objects embedded within graphic compositions
- unconventional relationships between typography and imagery
- asymmetry
- negative space
- object overlap
- real physical objects
- transformation from scattered elements into a deliberate composition

Do NOT copy the exact layouts.

Do NOT copy the typography.

Do NOT copy the objects.

Do NOT copy the colours.

Do NOT recreate any reference literally.

The references communicate the PRINCIPLE of the composition, not the exact design.

--------------------------------------------------
TYPOGRAPHY + OBJECT RELATIONSHIP
--------------------------------------------------

The headline should initially have objects interacting with its letterforms.

For example:

I [object] FIGURE

THINGS [object]

O[object]UT.

These are only conceptual examples.

Do not force an object into every line.

Some objects can sit between words.

Some can overlap letters.

Some can sit behind the headline.

Some can sit close to the headline and create visual tension.

The goal is for the typography and objects to feel like one designed artifact.

--------------------------------------------------
THE RESOLUTION INTERACTION
--------------------------------------------------

This is the most important interaction.

When the user voluntarily interacts with the objects, the composition begins to resolve.

The user should NOT be forced to interact.

They can ignore everything and scroll normally.

If they choose to explore:

1. Cursor enters the object field.
2. Nearby objects subtly react.
3. The cursor can show a very small contextual indicator such as:

LOOK

4. When the user discovers a meaningful object, it becomes slightly more prominent.
5. That object begins moving toward its eventual position.
6. Nearby objects subtly react and reposition.
7. Typography also begins changing position/spacing.
8. The whole composition gradually becomes more ordered.

IMPORTANT:

The objects and typography should reorganize TOGETHER.

Do not move the objects independently while leaving the typography completely static.

The final state should feel like the entire visual system has “clicked into place.”

--------------------------------------------------
FINAL RESOLVED STATE
--------------------------------------------------

The final state should be significantly clearer than the initial state.

The headline should become extremely legible:

I FIGURE
THINGS
OUT.

The objects should form a deliberate still-life composition around and/or within the typography.

The final arrangement should feel like:

- an editorial poster
- a contemporary still life
- a graphic composition
- a carefully art-directed photograph

It should NOT look like a grid.

It should NOT look like objects have simply been sorted into rows.

Use:

- scale contrast
- overlap
- proximity
- colour relationships
- negative space
- physical depth
- visual balance
- asymmetry

Some objects should remain close together.

Some can overlap.

Some can frame the typography.

Some can sit slightly away as supporting details.

The final composition should feel intentional enough that it could exist as a standalone artwork.

--------------------------------------------------
CURSOR INTERACTION
--------------------------------------------------

Use a sophisticated cursor-following interaction inspired by contemporary interactive studio websites.

The cursor should remain small.

Do not use a giant circle.

Do not use a glowing cursor.

Do not use neon.

Do not use a permanent trail.

When entering the collection:

small contextual indicator:
EXPLORE

When hovering over an interactive object:

LOOK

When an object has been discovered:

FOUND

When hovering over Work:

ENTER →

The indicator should follow the actual mouse with subtle easing/delay.

--------------------------------------------------
OBJECT PHYSICS
--------------------------------------------------

Objects should feel physical.

When the cursor approaches:

- shift slightly
- rotate slightly
- change depth subtly
- move relative to nearby objects

Use approximately 5–15px of movement.

Do not exaggerate.

The user should feel that their attention is disturbing the composition.

Objects should not constantly move when the user stops moving the cursor.

--------------------------------------------------
OPTIONAL DISCOVERY
--------------------------------------------------

The interaction must remain OPTIONAL.

There should be no:

- modal
- mandatory tutorial
- score
- timer
- progress bar
- “find 7 objects” instruction
- game UI
- reward system
- lives
- points
- level
- completion screen

The portfolio must remain a portfolio.

If the visitor never interacts:

they can simply scroll.

If the visitor is curious:

they can explore.

--------------------------------------------------
SCROLL BEHAVIOUR
--------------------------------------------------

Normal scrolling must always work.

Do not hijack the scroll.

If the user scrolls without interacting, transition naturally into Selected Work.

If the user has interacted with the collection, allow the composition to resolve briefly before continuing.

The interaction should enhance the homepage rather than block it.

--------------------------------------------------
HERO → WORK
--------------------------------------------------

Once the hero transitions to the work section:

the resolved composition can gently separate.

Objects can move away from the typography.

The headline can reduce in scale.

Then reveal:

SELECTED WORK

01

KUTIR

The transition should feel like:

a messy visual thought becoming a clear design problem.

Do not explicitly explain this.

--------------------------------------------------
COMPOSITIONAL PRIORITY
--------------------------------------------------

The hierarchy must be:

1. I FIGURE THINGS OUT.
2. The integrated object composition.
3. Supporting copy.
4. Navigation.

The objects should never compete with the headline.

But they should be interesting enough that a curious visitor wants to inspect them.

--------------------------------------------------
VERY IMPORTANT
--------------------------------------------------

The hero should NOT look like:

headline + decorations.

It should look like:

A single art-directed composition containing typography and physical objects.

Think:

TYPOGRAPHIC POSTER + STILL LIFE + OPTIONAL INTERACTIVE DISCOVERY.

The initial state is slightly unresolved.

The final state is composed.

The interaction is subtle.

The user has agency.

The website remains immediately understandable.

--------------------------------------------------
DO NOT CHANGE
--------------------------------------------------

Keep:

- current navigation
- current typography family
- large typography
- warm off-white background
- black primary type
- restrained overall palette
- supporting copy
- overall minimalist/editorial design system

Only redesign the HERO COLLECTION and its interaction.

The final goal is:

CLEAN ENOUGH TO UNDERSTAND.

INTERESTING ENOUGH TO EXPLORE.

PERSONAL ENOUGH TO REMEMBER.
